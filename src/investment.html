Scope of work

What is included, phase by phase. Six phases, one fixed price, no hourly billing.

Phase 1Discovery & content architecture $400
  • Full content inventory of the existing site, with all thirteen market pages catalogued.
  • Extraction and cleanup of every existing project entry (100+ projects) into a structured database: name, location, market, services provided, square footage, architect, year, and status.
  • Filter taxonomy design — the Market / Service / Location system that powers the new portfolio.
  • Selection of the twelve flagship case study projects with CEA leadership.
  • Sitemap and URL structure, including the redirect map from the current thirteen-page structure.
  • Asset audit: which projects have usable photography and which need new images.
Phase 2Design system & page design $900
  • Mobile-first design across the entire site. Every page, and the portfolio filters in particular, are designed for the phone before the desktop: comfortable tap targets, readable text without pinching, no horizontal scrolling, and fast loading on cellular. A large share of the architects, developers, and owners evaluating CEA are doing it from a job site on their phone.
  • Extraction of the existing homepage design language into a reusable system — color, type scale, spacing, buttons, cards — so the entire site finally matches the front door.
  • Portfolio grid design, mobile and desktop.
  • Standardized project card: uniform image crop, project name, city, FPME service badges, square footage.
  • Case study page template: hero, specification sidebar, narrative body, image gallery.
  • Interior page templates for services, about, team, contact, and employment.
  • Two rounds of design revisions included before build begins.

Phase 3Filterable portfolio build $1,400

The core of the project.

  • A single unified portfolio replacing all thirteen separate market pages.
  • Multi-select filtering by Market (13 categories), Service (Fire Protection, Plumbing, Mechanical, Electrical), and Location — combinable, so Hospitality plus Electrical in Charleston returns only matching work.
  • Each filtered view generates its own shareable, indexable link, useful in sales emails and for search engines.
  • Keyword search across all projects.
  • Migration and standardization of all existing projects into the new card format.
  • Image normalization: uniform aspect ratios, compression, modern formats, lazy loading, and declared dimensions, so the page never jumps as it loads.
  • Fully responsive, with thumb-friendly tap targets so the filters work properly on a phone.
  • No-results state, loading states, and clear-filter behavior.
Phase 4Flagship case study pages (12) $1,200

Twelve dedicated project pages, each individually built and written.

  • Hero image treatment.
  • Specification sidebar: location, size, market, services provided, architect, year, and CEA's role.
  • A written engineering narrative covering the challenge, the approach, and the outcome. Drafted by Sandbar from your existing material and submitted for technical accuracy review, with two rounds of revisions per case study included.
  • Project image gallery with lightbox.
  • Related-project links and a contextual call to action.
  • Client testimonial placed beside the project it actually describes.
  • 360 King Street is built first. Concealing an entire HVAC system through twelve chimney flues, with six new nail holes in the whole structure, is the strongest story on the site. It deserves the anchor page.

Phase 5Core site pages $700
  • Homepage refinement, keeping what already works and connecting it to the new portfolio.
  • Services overview plus four discipline pages: Fire Protection, Plumbing, Mechanical, Electrical.
  • About Us, CEA Team, and Testimonials.

Phase 6SEO & technical foundation $500
  • Unique, keyword-targeted title tag and meta description on every page; interior portfolio pages currently ship blank.
  • Descriptive alt text on every meaningful image.
  • LocalBusiness structured data for both the Charleston and Lexington offices, with consistent name, address, phone, and hours.
  • Project structured data on all twelve case study pages.
  • Open Graph and Twitter card tags, so links look right when shared or emailed.
  • Semantic HTML with correct heading hierarchy; XML sitemap, robots.txt, and canonical tags.
  • Google Search Console setup and verification.
  • Full 301 redirect map from all old URLs — no lost rankings, no broken links.
  • Core Web Vitals pass: page speed, layout stability, mobile usability.
  • Baseline keyword ranking report, so you can measure what this actually did.
